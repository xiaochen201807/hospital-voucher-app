# 石家庄心理医院 - 财务凭证与进销存自动化工作台 (Desktop App)

基于 **Rust + Tauri 2.0 + 现代深色轻奢前端设计** 打造的医院财务进销存凭证自动化客户端，专为财务及药库人员日常操作设计，彻底摆脱命令行与繁琐的手工 Excel 公式匹配。

---

## 🌟 核心功能特性

### 实际业务操作顺序
1. 药房提供出库表，执行【销售明细去重汇总】，得到销售汇总表。
2. 导出入库前数量金额总账，结合库管入库单执行【药房入库凭证】，导入入库凭证。
3. 入库凭证导入完成后重新导出数量金额总账，结合第 1 步销售汇总表执行【销售出库凭证】。
4. 将出库凭证导入系统；全部记账后，再用最终总账和库管库存表执行【账实库存核对】。

### 1. 📊 销售明细去重汇总 (Sales Rollup)
- **支持格式**：门诊与住院销售明细表（`.xlsx` 与旧版 `.xls`）。
- **智能汇总**：自动合并相同药品的多行销售，累加实发数量，按销售进价与零售价重新计算准确的成本及售价总金额。
- **可视化结果看板**：实时展示原始明细行数、汇总后品种数、销售总件数、总进价与总零售金额，并支持一键打开生成文件或在文件夹中定位。

### 2. 📥 药房入库凭证生成 (Pharmacy Inbound Voucher)
- **支持类别**：中药饮片入库单、西药药品入库单。
- **按供应商连续输出**：同一供应商的所有入库明细连续输出，随后只生成一个供应商汇总贷方分录；简称、全称和截断名称按标准供应商编码合并。
- **未匹配人工指定**：未匹配药品可从总账候选科目中手工选择，重新生成时仅覆盖明确选择的明细。
- **往来单位智能匹配**：自动从 22 家往来供应商字典中匹配对应编码（如华润益生 `002`、河北国泰 `004`、河北蕴德 `005`），并自动生成标准摘要（如 `华润河北益生到货`）。
- **金额按分平衡**：入库明细和供应商汇总均按人民币分累计，借贷金额逐分相等，避免逐笔浮点取整造成尾差。
- **⚖️ 借贷平衡双向核验天平**：
  - **借方**：库存商品 / 中药饮片各药品分录入账金额汇总。
  - **贷方**：应付账款各供应商往来分录金额汇总。
  - **指示灯**：差额为 0.00 时显示绿色“借贷完美平衡”，若存在差额则显示红色警示并标明差额数值。

### 3. 📤 销售出库凭证自动生成 (Sales Outbound Voucher)
- **三表智能关联**：一键关联【第一步生成的销售汇总表】、【入库凭证导入后重新导出的数量金额总账表】、【凭证导入模板】；双 Sheet 销售结果会优先读取去重后的“销售明细”Sheet，不重复使用原始明细。
- **数量安全校验**：生成前校验每个存货的累计出库数量不得超过所选总账期末结存，发现总账阶段选错或销售表重复时直接阻止生成并给出原因。
- **尾差自动平衡**：仅当本次出库累计数量恰好使存货数量变为 0 时，将总账账面金额与出库基础金额的差额摊到该存货最后一笔出库商品；总账中历史遗留的“数量为 0、金额非 0”记录不参与本次尾差处理。贷方明细按分取整后，第 1 行自动填入等额借方平衡金额。
- **存货编码精准映射**：结合生产厂家与规格，全词精准匹配总账中的存货科目编码（如 `1201_ZY0124` 鸡血藤（蕴德））。
- **自动月末记账**：自动根据单据最大日期智能锁定入账日期（如 `2026-08-31`）。
- **未匹配新药告警看板**：对未在总账中建档的新进药品，凭证中安全留空科目编码并以橙色高亮卡片提示财务人员核对，绝不错串老批次账目。
- **未匹配人工指定**：未匹配项会展示总账候选科目，可直接人工选择后重新生成凭证；未选择的项目继续安全留空。

### 4. ⚙️ 厂家与字典配置中心 (Dictionary & Rules)
- **可视化增删改查**：直接管理 `factory_mapping.json`。
- **厂家全称 ➔ 规范简称表**：已预置包含 `河北蕴德药业有限公` -> `蕴德` 等 18 家主流厂家对照。
- **严格厂家后缀药品名单**：支持一键添加需严格按厂家区分的新药（如 `海螵蛸`），严禁系统回退到历史通用老编码。
- **特殊编码覆盖**：支持为指定药品单独强行指定编码或强制安全留空。

## 🚀 运行与打包指南

### 开发模式运行
在 `desktop_app` 目录下：
```bash
# 1. 安装依赖（首次运行）
npm install

# 2. 启动桌面客户端
npm run tauri dev
```

### 生成独立客户端安装包 (Windows / macOS)
```bash
npm run tauri build
```
- **Windows**：将在 `src-tauri/target/release/bundle/msi/` 或 `nsis/` 生成一键安装包 `.exe` 或 `.msi`。
- **macOS**：将在 `src-tauri/target/release/bundle/dmg/` 生成 `.dmg` 安装镜像。
