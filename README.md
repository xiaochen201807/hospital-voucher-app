# 西药销售统计与凭证导入自动化工具集

本项目包含三个核心自动化处理脚本，用于医院药房的销售统计、出库凭证导入与入库凭证导入全流程：
1. **`process_sales.py`**：读取西药销售汇总表，按【药品名称、规格、剂型、制药厂】4列去重汇总，生成排版标准的第二个 Sheet（销售明细表）。
2. **`generate_voucher.py`**：读取销售明细表及财务总账表，自动匹配存货辅助账编码与单价，自动生成填报好的出库【凭证导入模板.xlsx】（金额计入贷方）。
3. **`generate_inbound_voucher.py`**：读取【西药-药品入库单.xlsx】及财务总账/辅助核算表，自动匹配存货辅助账编码，自动生成入库【凭证导入模板.xlsx】（金额计入借方）。

## 二、脚本一：销售明细表生成 (`process_sales.py`)

### 功能与规则
1. **去重与分组**：严格以 `药品名称` + `规格` + `剂型` + `制药厂` 4 个字段作为联合唯一键进行去重聚合。
2. **运算逻辑**：
   - `数量`：SUM 求和累加
   - `进价金额`：SUM 求和累加
   - `零价金额`：SUM 求和累加
   - `单位`：保留药品销售单位
   - `库存`：保留当前库存数值
3. **排序逻辑**：默认按 **【数量】降序排列**；数量相同时按药品名称拼音排序。
4. **输出排版**：
   - Row 1：合并 A~I 列居中大标题（如 `2026.8月西药销售明细表`）
   - Row 2：标准表头（带全边框）
   - Row 3~N：数据明细行（对齐美观、带细边框）
   - Row N+1：合计行（统计原记录条数、数量总计、进价总金额、零价总金额）

### 使用命令

```bash
# 1. 最简运行（自动识别当前目录下的销售表并生成第二个 Sheet）：
python3 process_sales.py

# 2. 指定销售表文件：
python3 process_sales.py "2026.8月西药销售表.xls"

# 3. 另存为新文件（避免覆盖原文件）：
python3 process_sales.py "2026.8月西药销售表.xls" -o "西药销售明细_汇总版.xls"

# 4. 自定义第二个 Sheet 的名称（默认命名为“销售明细”）：
python3 process_sales.py "2026.8月西药销售表.xls" -s "8月销售明细"
```

## 三、脚本二：凭证导入模板生成 (`generate_voucher.py`)

### 生成结构与分录说明

生成的【凭证模版】Sheet 严格按照会计借贷凭证规范排列：
- **第 1 行（表头）**：26 列标准字段名称。
- **第 2 行（借方分录，分录序号为 1）**：在表头下方自动插入一行，预置日期、凭证字（记）、分录序号（1）、币别（RMB）、汇率（1），**借方金额/科目代码/科目名称留空**，专门用于财务人员填写借方总金额与对应科目。
- **第 3 ~ 56 行（贷方明细，分录序号从 2 开始递增）**：54 行药品存货明细，自动填入存货辅助编码、销售数量、总账成本单价及贷方金额。

| 列序号 | 列名 | 借方行（分录序号 1） | 贷方明细行（分录序号 2 开始递增） |
| :---: | :--- | :--- | :--- |
| **1** | **日期** | 月末最后一天（如 `2026-08-31`） | 月末最后一天（如 `2026-08-31`） |
| **2** | **凭证字** | 固定填入 **记** | 固定填入 **记** |
| **3** | **凭证号** | 留空不用处理 | 留空不用处理 |
| **4** | **附件数** | 留空不用处理 | 留空不用处理 |
| **5** | **分录序号** | **1** | **从 2 开始逐行递增 (2, 3, 4...)** |
| **6** | **摘要** | 留空待填（如“结转8月西药销售成本”） | 留空不用处理 |
| **7** | **科目代码** | 留空待填（如借方主营业务成本科目） | 留空不用处理 |
| **8** | **科目名称** | 留空待填 | 留空不用处理 |
| **9** | **借方金额** | **留空待填（填写借方总金额）** | 留空不用处理 |
| **10**| **贷方金额** | 留空不用处理 | 计算：销售数量 × 总账单价（如 `14193.06`） |
| **11~15** | 客户/供应商/职员/项目/部门 | 留空不用处理 | 留空不用处理 |
| **16**| **存货** | 留空不用处理 | 辅助账编码（如 `1201_XY0001` -> `XY0001`） |
| **17~21** | 是否限定/自定义辅助核算 | 留空不用处理 | 留空不用处理 |
| **22**| **数量** | 留空不用处理 | 销售表的销售数量（如 `33793`） |
| **23**| **单价** | 留空不用处理 | 总账表的单价（加权成本单价，如 `0.42`） |
| **24**| **原币金额** | 留空不用处理 | 计算：销售数量 × 总账单价（如 `14193.06`） |
| **25**| **币别** | 固定填入 **RMB** | 固定填入 **RMB** |
| **26**| **汇率** | 固定填入 **1** | 固定填入 **1** |

### 使用命令

```bash
# 1. 最简运行（自动查找销售表、总账表及凭证模板，生成 凭证导入模板_已生成.xlsx）：
python3 generate_voucher.py

# 2. 指定三个源文件路径：
python3 generate_voucher.py \
  -s "2026.8月西药销售表.xls" \
  -l "石家庄心理医院_数量金额总账_20260903150759.xlsx" \
  -t "凭证导入模板.xlsx"

# 3. 指定输出目标文件名：
python3 generate_voucher.py -o "2026年8月凭证导入_西药销售.xlsx"

# 4. 手动指定月末入账日期（默认会自动推导）：
python3 generate_voucher.py -d "2026-08-31"

# 5. 未匹配到总账单价的新药，自动回退使用销售表进价单价：
python3 generate_voucher.py --fallback-price

# 6. 直接更新覆盖原模板文件：
python3 generate_voucher.py -o "凭证导入模板.xlsx"
```

## 四、数据核对与未匹配药品处理指南（重要）

### 1. 匹配机制与数据审计结果
运行脚本后，系统会对所有分录进行核对：
- **总分录行数**：54 行（对应 54 种聚合后的西药明细）。
- **成功匹配**：**48 行 (88.9%)**，辅助核算编码、总账成本单价、销售数量、贷方金额均 100% 自动对齐且精确计算。
- **未匹配/待处理**：**6 行 (11.1%)**，属于财务系统中暂未建账的新药。

### 2. 未匹配药品的 6 种明细清单

在当前的【数量金额总账】以及【凭证模板 Sheet 3（辅助核算项目）】中，以下 6 种药品暂无对应科目：

| :---: | :---: | :--- | :--- | :---: | :---: | :---: | :---: | :---: |
| **34** | Row 35 | **布南色林片** | 4mg*14片/盒 | 579 | *未匹配(空)* | *无* | 3.2357 元 | 1,873.47 元 |
| **42** | Row 43 | **盐酸齐拉西酮胶囊** | 20mg*24粒/盒 | 247 | *未匹配(空)* | *无* | 1.6542 元 | 408.59 元 |
| **45** | Row 46 | **右佐匹克隆片** | 3mg*7片/盒 | 105 | *未匹配(空)* | *无* | 0.5671 元 | 59.55 元 |
| **46** | Row 47 | **盐酸安非他酮缓释片(Ⅱ)** | 150mg*30片/盒 | 91 | *未匹配(空)* | *无* | 1.8333 元 | 166.83 元 |
| **50** | Row 51 | **地达西尼胶囊** | 2.5mg*7粒/盒 | 77 | *未匹配(空)* | *无* | 13.8800 元 | 1,068.76 元 |
| **52** | Row 53 | **氢溴酸西酞普兰片** | 20mg*16片/盒 | 64 | *未匹配(空)* | *无* | 2.3494 元 | 150.36 元 |

### 3. 未匹配原因分析
1. **总账建账范围**：总账表中当前西药存货科目只建到了 `1201_XY0001` 至 `1201_XY0081`（共 81 个品种）。
2. **辅助账字典范围**：凭证模板 Sheet 3（辅助核算项目数据）中的西药存货也只维护到 `XY0081`（便通片）。
3. **业务原因**：这 6 种药品属于药房新引入销售、但**财务系统尚未在存货辅助核算中建立对应科目与成本单价**的药品（HIS 编码如 `013734`、`013735` 等）。

### 4. 建议处理方案

#### 方案 A：标准财务建账流程（推荐）
1. 财务人员在财务软件的“存货辅助核算”中，为上述 6 种药品新增编码（例如顺延分配 `XY0082` ~ `XY0087`）；
2. 在财务系统中录入该药品的入库/期初单价并重新导出总账，或直接在【凭证导入模板.xlsx】Sheet 3 中追加这 6 行辅助核算编码；
3. 重新执行 `python3 generate_voucher.py`，脚本即可全自动 100% 匹配。

#### 方案 B：临时以药房进价暂估入账
如果希望立即生成带有金额的凭证，可以使用 `--fallback-price` 参数：
```bash
python3 generate_voucher.py --fallback-price
```
- **效果**：对于这 6 种总账中无单价的药品，单价将自动取自销售表的采购进价计算贷方金额；
- **后续操作**：存货辅助账编码在 Excel 或导入财务系统后手工指定即可。

## 五、脚本三：入库凭证导入模板生成 (`generate_inbound_voucher.py`)

### 功能与规则（完全匹配《凭证导入模板-入库.xlsx》规范）
1. **数据源解析**：自动读取 `西药-药品入库单.xlsx`，提取药品名称、规格、数量、进价、进价金额、供应商等入库明细。
2. **存货与供应商辅助核算双重匹配**：
   - **存货编码**：从总账表与模板 Sheet 3 辅助核算字典中匹配 `XY...` 编码（未建档新药安全留空并在终端输出清单）；
   - **供应商编码**：从模板 Sheet 3 辅助核算字典中自动将供应商名称匹配为对应编码（如 `001` 国药乐仁堂、`002` 华润河北益生、`004` 河北国泰、`007` 石药集团河北中诚、`009` 湖南洞庭药业）。
3. **按供应商自动分组与借贷平衡凭证生成**：
   - **每个供应商名下的借方存货分录（科目代码 1201）**：
     * 摘要：`{供应商简称}到货`（例如 `国药乐仁堂到货`、`华润河北益生到货`）
     * 借方金额：该药品采购进价金额
     * 存货列：填入存货辅助编码（如 `XY0015`）
     * 数量 / 单价 / 原币金额：入库数量 / 进价单价 / 进价金额
     * 供应商列：留空
   - **每个供应商名下的贷方应付账款汇总分录（科目代码 220201）**：
     * 摘要：`{供应商简称}到货`
     * 贷方金额：该供应商所有借方药品金额之和
     * 供应商列：**填入该供应商对应的辅助核算编码（如 `001`、`002` 等）**
     * 存货列 / 数量 / 单价：留空
   - 全局分录序号从 1 递增，整张凭证借贷双方完全平衡。

### 使用命令

```bash
# 默认一键运行（自动搜索西药入库单、总账表与模板）
python3 generate_inbound_voucher.py

# 生成中药入库凭证
python3 generate_inbound_voucher.py -i "中药-药品入库单.xlsx" -o "凭证导入模板_中药入库_已生成.xlsx"

# 指定输出文件名
python3 generate_inbound_voucher.py -o "2026年8月入库凭证导入.xlsx"

# 指定凭证日期或凭证号
python3 generate_inbound_voucher.py -d 2026-08-31 -v 20
```

## 六、厂家全称与简写映射配置文件 (`factory_mapping.json`)

为了精准处理中药/西药中带有厂家后缀（如 `（蕴德）`、`（国瑞堂）`、`（国松堂）`）的存货科目匹配，系统引入了统一的配置文件 [factory_mapping.json](file:///Users/youyou/Downloads/python/factory_mapping.json)。

### 配置文件结构：
```json
{
  "factory_abbreviations": {
    "河北蕴德药业有限公": "蕴德",
    "河北蕴德药业有限公司": "蕴德",
    "河北国瑞堂药业有限公司": "国瑞堂",
    "河北国松堂制药有限公司": "国松堂"
  },
  "strict_vendor_suffix_drugs": [
    "海螵蛸"
  ],
  "drug_code_overrides": {
    "海螵蛸（蕴德）": ""
  }
}
```

### 匹配逻辑保障：
1. **优先带厂家后缀匹配**：当入库单/销售表中的厂家匹配到简称（如 `河北蕴德药业有限公` -> `蕴德`）时，自动优先匹配 `{药品名称}（{厂家简称}）`（如 `鸡血藤（蕴德）` 精确匹配科目 `ZY0124`，绝不误匹配到 `国瑞堂` 的 `ZY0123`）。
2. **防通用全词误匹配**：对于列入 `strict_vendor_suffix_drugs` 的药品（如 `海螵蛸`），由于历史科目 `ZY0106`（海螵蛸）属于旧批次/其他供应商，系统**强制要求必须匹配 `海螵蛸（蕴德）`**，绝不回退至旧通用科目 `ZY0106`。未建账时自动列入提示清单并存货留空。
3. **支持一键配置存货编码**：若财务系统已为新药建好编码（如 `ZY0259`），可直接在 `drug_code_overrides` 中填入：
   ```json
   "drug_code_overrides": {
     "海螵蛸（蕴德）": "ZY0259"
   }
   ```
   重新运行脚本即可全自动完成带编码的凭证填报！

## 九、常见问题解答 (FAQ)

### Q1: 运行提示 `ModuleNotFoundError: No module named 'xlrd'` 或 `openpyxl`？
**解答**：说明依赖尚未安装，执行 `pip3 install -r require.txt` 即可。

### Q2: 提示 `error: externally-managed-environment`？
**解答**：这是 macOS Homebrew Python 的安全保护机制，请在 pip 命令后加上 `--break-system-packages`：
```bash
pip3 install -r require.txt --break-system-packages
```
